# MedStudy — бот регистрации на мастер-класс

Telegram-бот, который регистрирует пользователей на мастер-классы MedStudy (медицина и тех/IT), задаёт вопросы сегментации, выдаёт бонус и присылает цепочку напоминаний.

## Как работает

1. `/start` — три вопроса кнопками: кто поступает, направление, Прага или переезд.
2. Если пользователь не ответил за `NO_ANSWER_DELAY_MIN` минут (меняется командой `/setreminddelay`) — одно напоминание «Нет ответа» с теми же кнопками. Если он молчит и дальше, после `/setleaddelay` минут создаётся лид в Битрикс24.
3. После последнего ответа — бонус со ссылкой на платформу и подтверждение записи на мастер-класс выбранного направления. Регистрация попадает в Google Sheets.
4. Напоминания по времени мастер-класса:
   - за 3 дня — с кнопкой «Напомнить за 1 час»;
   - за 1 день — с выбором «Приду лично» / «Подключусь онлайн» (выбор сохраняется в базе и таблице);
   - за 1 час;
   - за 5 минут — со ссылкой на трансляцию;
   - после окончания (`MK_DURATION_MIN`) — «Мастер-класс завершился»;
   - через час после окончания — предложение пробной недели.

Напоминания, время которых уже прошло на момент регистрации, не отправляются. Очередь хранится в SQLite, поэтому перезапуск бота ничего не теряет.

Любое сообщение пользователя пересылается администраторам. Чтобы ответить, достаточно ответить реплаем на пересланное сообщение.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Узнай свой Telegram ID (например, через [@userinfobot](https://t.me/userinfobot)).
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`, `ADMIN_IDS`, `PLATFORM_URL`.
4. Каждый админ должен один раз написать боту `/start`, чтобы бот мог присылать ему сообщения.

### Вступление в группу перед доступом к платформе (необязательно)

Если задан `CHANNEL_URL`, ссылку на платформу (бонус, «Мастер-класс завершился», пробная неделя) человек получает только после вступления в группу. Он видит кнопки «Вступить в группу» и «Я вступил(а)», бот проверяет участие и только тогда показывает кнопку платформы. Тем, кто уже в группе, кнопка платформы показывается сразу.

1. Укажи ссылку-приглашение в `CHANNEL_URL` или командой `/setchannel` в боте (она имеет приоритет).
2. Добавь бота **администратором** в эту группу или канал (права можно выдать минимальные). Добавлять должен один из админов бота. Бот сам запомнит группу и напишет админам «Бот подключён к группе».

Пока бот не подключён к группе, вступление не проверяется: человек видит и кнопку группы, и кнопку платформы. Состояние видно в `/stats`.

### Лиды в Битрикс24 (необязательно)

Если человек начал опрос и замолчал дольше `LEAD_DELAY_MIN` минут (по умолчанию 60, меняется командой `/setleaddelay`), бот создаёт лид в Битрикс24. На одного человека создаётся один лид. В лид попадают имя, @ник и ссылка на Telegram, Telegram ID, шаг, на котором человек остановился, и ответы, которые он успел дать. Если потом человек всё же зарегистрируется, бот допишет в ленту лида комментарий «Зарегистрировался позже» с ответами. Админы лиды не создают.

1. В Битрикс24: «Разработчикам» → «Другое» → «Входящий вебхук», право **CRM (crm)**. Адрес вида `https://компания.bitrix24.ru/rest/1/abc123/` укажи в `BITRIX_WEBHOOK_URL`. Это секрет, храни его только в `.env`.
2. В `BITRIX_SOURCE_ID` укажи ID источника лида. Список источников: метод `crm.status.list` с фильтром `ENTITY_ID=SOURCE`. По умолчанию `OTHER`.

Чтобы лид не создавался раньше напоминания «Нет ответа», держи `/setleaddelay` больше `/setreminddelay`: иначе бот предупредит. Ошибки Битрикса пишутся в лог, повторная попытка для того же человека — не раньше чем через 5 минут. Статус и число созданных лидов видны в `/stats`.

### Google Sheets (необязательно)

1. В [Google Cloud Console](https://console.cloud.google.com/) создай проект и включи **Google Sheets API**.
2. Создай сервисный аккаунт, добавь ему ключ в формате JSON и сохрани файл как `google-credentials.json` в корне проекта.
3. Создай таблицу, переименуй лист в `Регистрации` (или укажи другое имя в `GOOGLE_SHEET_NAME`) и выдай доступ «Редактор» на email сервисного аккаунта.
4. Укажи `GOOGLE_SHEET_ID` — это часть URL таблицы между `/d/` и `/edit`.

Заголовки колонок бот создаст сам. Если Sheets не настроен или недоступен, бот продолжит работать, а ошибки запишет в лог.

## Запуск

```bash
npm install
npm run dev      # локально, с перезапуском при изменениях
npm run build && npm start   # продакшен
```

### Docker

```bash
docker build -t medstudy-bot .
docker run -d --name medstudy-bot --restart unless-stopped \
  --env-file .env \
  -e GOOGLE_APPLICATION_CREDENTIALS=/app/google-credentials.json \
  -v "$PWD/google-credentials.json:/app/google-credentials.json:ro" \
  -v medstudy-data:/app/data \
  medstudy-bot
```

## Команды администратора

| Команда | Что делает |
| --- | --- |
| `/stats` | Статистика регистраций и текущие ссылки |
| `/export` | CSV со всеми пользователями |
| `/broadcast` | Рассылка: выбор сегмента (все, медицина, тех, очно, онлайн), сообщение, предпросмотр и подтверждение |
| `/cancel` | Отменить подготовку рассылки |
| `/setlink med\|tech <url>` | Ссылка на онлайн-трансляцию для напоминания за 5 минут |
| `/setplatform <url>` | Ссылка на образовательную платформу |
| `/setchannel <url>` | Ссылка на группу, в которую нужно вступить перед платформой (`https://t.me/...`) |
| `/setreminddelay <минуты>` | Через сколько минут без ответа прислать напоминание «Нет ответа» |
| `/setleaddelay <минуты>` | Через сколько минут без ответа создать лид в Битрикс24 |
| `/setdate med\|tech ДД.ММ.ГГГГ ЧЧ:ММ` | Дата и время мастер-класса по Праге, например `/setdate med 23.11.2026 14:00` |
| `/admins` | Список админов |
| `/addadmin <id>` | Добавить админа (или ответить `/addadmin` реплаем на пересланное сообщение пользователя) |
| `/removeadmin <id>` | Удалить админа, добавленного через бота |
| `/reset` | Сбросить свою регистрацию, чтобы пройти опрос заново (для теста). То же делает кнопка под `/admin` |
| `/admin` | Список команд |

Админы из `ADMIN_IDS` — главные: через бота их удалить нельзя. Добавленный админ должен один раз написать боту `/start`, чтобы бот мог присылать ему сообщения.

Ссылку на трансляцию нужно задать до начала мастер-класса, иначе в напоминании за 5 минут будет «ссылка появится здесь в ближайшие минуты». Текущее состояние ссылок видно в `/stats`.

## Где менять тексты и даты

- Тексты сообщений и кнопок — `src/texts.ts`.
- Направления и адрес — `src/config.ts`.
- Даты — командой `/setdate` в боте. Начальные значения берутся из `MED_STARTS_AT` / `TECH_STARTS_AT` в `.env`, но дата, заданная через `/setdate`, сохраняется в базе и имеет приоритет.

После `/setdate` напоминания всех зарегистрированных на это направление пересоздаются под новую дату, в том числе те, что уже были отправлены для старой даты.
